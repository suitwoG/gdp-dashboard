# LexiQuest v3 — демо геймифицированной платформы по праву

Этот репозиторий содержит третью версию прототипа LexiQuest — учебной платформы по
юридическим дисциплинам, выполненной в стиле Duolingo. Версия v3 собрана на ванильном
JavaScript и не требует установки зависимостей: достаточно запустить встроенный Node.js
сервер и открыть браузер.

## Что нового в v3

- Полностью автономный фронтенд без внешних библиотек — работает из коробки.
- Обновлённый визуальный стиль с яркой дорожкой уроков, маскотом и адаптивной
  сеткой.
- Реалистичные демо-данные: курсы, ежедневные цели, лиги, магазин и профиль.
- Интерактивность: переключение между разделами, выбор курса, подсказки маскота,
  покупка предметов с проверкой баланса.
- Панель «Просмотр версий» в верхней части приложения позволяет мгновенно переключаться
  между визуальными темами v2, v3 и v4 и видеть отличия маскотов и палитр.

## Запуск

```bash
npm run dev
```

Сервер стартует по адресу [http://localhost:3000](http://localhost:3000). Скрипт не требует
`npm install` — все файлы уже присутствуют в репозитории.

## Структура

```
public/
  index.html   — основной интерфейс
  styles.css   — тема и оформление
  app.js       — данные и логика взаимодействия
server.mjs     — лёгкий сервер на Node.js
package.json   — скрипты запуска
```

## Возможности демо

- **Дорожка уроков** с отображением статусов (книга, галочка, звезда, сундук, замок).
- **Маскот Lex**, который реагирует на прогресс и даёт советы.
- **Ежедневные задания** с прогресс-барами и бонусным сундуком.
- **Лига** с подсветкой текущего места пользователя.
- **Магазин** с покупкой бонусов за монеты и проверкой баланса.
- **Профиль** с общей статистикой, достижениями и лентой активности.

> Обратите внимание: это демонстрационный прототип. Данные статичны и не сохраняются
> между перезапусками.
