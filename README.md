# ⚖️ Lex Moscua

Lex Moscua — геймифицированная образовательная платформа для изучения юридических дисциплин. Приложение построено на Streamlit и включает дорожку уроков, ежедневные цели, систему наград, таблицу лидеров и административную панель для управления контентом.

## Возможности

- Регистрация и авторизация пользователей с безопасным хранением паролей.
- Несколько курсов по различным направлениям права (теория права и конституционное право включены по умолчанию).
- Древовидная траектория обучения с состояниями уроков (новый, пройден, с отличием, заблокирован).
- Интерктивные викторины с мгновенной обратной связью и начислением опыта/монет.
- Ежедневные цели, отслеживание серии, достижения и награды за завершение модулей.
- Таблица лидеров и магазин внутриигровых бонусов.
- Админ-панель для добавления курсов, модулей и уроков без правки кода.

## Локальный запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите приложение:
   ```bash
   streamlit run streamlit_app.py
   ```

3. Откройте ссылку из консоли (обычно `http://localhost:8501`).

При первом запуске автоматически создаётся база данных `data/lex_moscua.db` и тестовый администратор `admin@lexmoscua.ru` с паролем `LexAdmin2024!`.

## Структура проекта

- `streamlit_app.py` — основной код приложения: интерфейс, логика авторизации, управление прогрессом, магазин, админ-панель.
- `data/` — директория с данными. При первом запуске создаётся SQLite-база с начальными курсами.
- `requirements.txt` — список зависимостей.

## Создание собственного контента

Войдите как администратор и перейдите в раздел «Администрирование». Там можно:

- добавлять новые курсы с описанием и уровнем сложности;
- создавать модули, задавая порядок и награды;
- наполнять модули уроками: теория, краткое описание и проверочный вопрос с вариантами ответов.

Новые элементы появляются сразу и доступны обучающимся.
